# 比较优势（Comparative Advantage）

提出者：[[people/david-ricardo|大卫·李嘉图]]。在本来源中，它的叙事功能是**给出一个前提条件**：国际分工只有在运输成本足够低时才划算。

## 来源的表述

> 「简单来说就是各地按相对优势分工，再通过贸易交换，从而取得收益。」

## 关键推论：运输成本是前提

来源的推理链是本页最有价值的部分：

1. 比较优势理论说分工 + 交换双方都获益；
2. **但分工要划算，运输费就必须足够低**；
3. 在传统[[concepts/break-bulk-shipping|件杂货运输]]下，东亚工厂即使人工便宜，港口装卸漫长、周转慢、破损与被盗都可能把省下的钱吃掉；
4. 对某些货物，**损耗比例可能超过 10%**；
5. 结果是：生产端便宜一点，送到消费者手里却未必还有优势。

## 被集装箱打开之后

运费坍塌到占零售价 1%~2%（见[[concepts/economies-of-scale|规模经济]]）后，企业的账变了：

> 「把原料从澳洲运到东亚，加工后再把成品运去欧美，即使多走一大段海路，总成本仍可能低于在消费国生产。」

这是[[hub/timeline|全球产业转移]]得以发生的经济学前提。

## 不确定性与争议

- 来源把比较优势简化为「按相对优势分工」，省略了其核心机制——**机会成本**的比较，这是常见但重要的简化。
- 来源未讨论比较优势理论的现代批评（要素价格均等化、贸易条件恶化、全球价值链的权力分配）。
- 「损耗超过 10%」未注明货物类别与出处。
