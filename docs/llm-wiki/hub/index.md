## Index Rules

- 每个页面只列一次，并附一行用途说明。
- 页面之间使用相对 Markdown 链接；页面正文引用 ../raw/ 中的具体来源。
- 同一名称的实体跨来源出现时，先合并到已有页面，冲突显式记录。
- 地点、事件等来源覆盖度低但数量多的实体类型，允许合并为索引页；拆分判据写在索引页内。
- 已废弃页面移动到归档区前，先修复入链并更新本索引。
