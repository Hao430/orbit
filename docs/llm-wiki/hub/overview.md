# Knowledge Base Overview

当前收录用户指定摄取的内容。首批来源为 B站科普视频《集装箱革命》，用于检验从音视频字幕到结构化 Wiki 的完整链路。

## Current Synthesis

首批来源产出三层结构：

- **实体层**：6 位人物、8 组组织、2 艘船、2 类技术物、20+ 地点、10 个事件
- **概念层**：10 个概念页（交易成本、标准化、规模经济、网络外部性、比较优势、精益生产、零库存、供应链韧性、件杂货运输、门到门运输）

该综合目前**单一来源**，具体数字尚未与一手研究交叉验证。
