# 马克·莱文森（Marc Levinson）

经济学家与历史研究者，本来源中关于「集装箱出现前的港口成本结构」的数据主要引自他的测算。

## 在本来源中被引用的数据

| 结论 | 数值 |
|---|---|
| 中型货船一年中趴在港口装卸的时间占比 | 超过一半（>50%） |
| 美国→欧洲运输中，海上航行成本占总运费比例 | 25%~40% |
| 码头装卸与港口停留占总运费比例 | 60%~75% |
