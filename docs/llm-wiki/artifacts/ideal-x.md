# 理想 X 号（Ideal X）

第一艘商业集装箱船。原为二战时期留下的旧游轮，经甲板加装特制钢架后，于 1956 年 4 月 26 日完成历史性首航。

## 船舶档案

| 项目 | 内容 |
|---|---|
| 前身 | 二战时期留下的旧游轮 |
| 改装 | 甲板加装特制钢架 |
| 载箱量 | 58 个银白色铝制货箱 |
| 起运港 | [[places/ports|纽瓦克港]]（新泽西） |
| 目的港 | [[places/ports|休斯顿港]] |
| 航程用时 | 6 天 |
| 运营方 | [[orgs/sea-land]] / [[people/malcolm-mclean]] |
| 首航日期 | 1956-04-26 |

## 经济意义（本来源最核心的一组数字）

| 船型 | 装卸成本 |
|---|---|
| 理想 X 号 | **每吨 15.8 美分** |
| 同日隔壁传统散货船 | **每吨 5.83 美元** |
| 降幅 | **97% 以上** |

来源用「在航运界投下了一颗核弹」形容这一结果。

> ⚠️ 两个成本数字的原始出处未给出。按字面计算，5.83 美元 / 0.158 美元 ≈ 36.9 倍，与「下降 97% 以上」（即剩余不足 3%，约 34 倍）大体自洽，但精确比值应以一手数据为准。

## 与后续船型的对照

在[[orgs/carriers|船舶巨型化]]的演进表里，理想 X 号的 58 箱是起点，今天最大船已突破 24000 标准箱——相差约 400 倍。

## 证据与不确定性

- 「二战旧游轮」这一前身说法与业界通说一致（原为 T2 型油轮改造），但来源未给出原船名。
- 58 个箱子、6 天航程、15.8 美分/吨 三个数字均属二手转述。
- 来源另处提到「1956 年 4 月 26 日，理想 X 号载着 58 个铝制货箱离开纽瓦克，六天后抵达休斯顿」——注意 4 月 26 日在来源中出现两次，一次作为「加装钢架、起重机作业」的场景，一次作为「启航」时间，存在轻微叙事重叠。
