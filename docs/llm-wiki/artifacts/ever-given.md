# 长赐号（Ever Given）

2021 年在[[places/ports|苏伊士运河]]搁浅的超大型集装箱船。在本来源中，它是「效率极致 = 韧性脆弱」这一论点的核心实证。

## 船舶档案

| 项目 | 内容 |
|---|---|
| 船长 | 400 米 |
| 载箱量 | 将近 2 万个集装箱 |
| 事故日期 | 2021-03-23 |
| 事故原因 | 穿越运河时遭遇强风和沙尘暴，船身一歪 |
| 阻塞时长 | 6 天 |
| 形态描述 | 「像一根巨大的蝎子一样死死地横着卡在运河河道里」 |

## 经济冲击（本来源引用数据）

| 指标 | 数值 |
|---|---|
| 苏伊士运河承载的全球贸易占比 | 约 12% |
| 排队船舶规模 | 几百艘，几十公里长队（红海与地中海） |
| 每小时被卡货物价值 | 4 亿美元 |
| 每天冻结的全球贸易额 | 96 亿美元 |
| 缺货表现 | 宜家家具、英国超市货架、造卫生纸的木浆 |

> ⚠️ 4 亿美元/小时 与 96 亿美元/天 相互自洽（4×24=96），但两者可能同源推导，不构成独立验证。该数据未注明出处。

## 论证作用

来源用它说明：[[concepts/lean-production|精益生产]] 与[[concepts/zero-inventory|零库存]] 把供应链绷到极紧后，单点故障会被放大成全局停摆。

> 「原来我们的现代生活竟然脆弱到，可以被一艘卡在泥巴里的集装箱船给按下暂停键。」
