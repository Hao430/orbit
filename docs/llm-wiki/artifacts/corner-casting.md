# 角件（Corner Casting）

位于集装箱八个角的坚固金属结构，带标准化椭圆孔。它是让集装箱既能被起重机吊起、又能在船舱里多层堆叠并在风浪中不散的关键零件。

> 原名错录说明：来源 AI 字幕将「角件」误录为「矫健」，正确的行业术语是「角件」或「角配件」。此修正记录于[[sources/transcript-bv12iyvz6evt|逐字稿清洗表]]。

## 技术要求（来源给出的两个约束）

1. **被吊起**：需要可靠地卡住起重机悬索 → 标准化椭圆孔；
2. **被堆叠**：像乐高积木一样一层层叠起来，在风浪中不散 → 八角受力均匀。

## 为什么它是「最后一个壁垒」

[[concepts/standardization|标准化]]解决了尺寸，但尺寸本身不足以让箱子跨公司流转：如果角件孔位与吊具不通用，箱子仍然无法被别人的起重机吊起。角件的开放使「箱体」真正变成可互换的单元，从而支撑[[concepts/door-to-door|门到门运输]]。
