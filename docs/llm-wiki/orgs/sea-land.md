# 海陆公司（Sea-Land）

[[people/malcolm-mclean]]旗下的航运公司，[[artifacts/ideal-x]]首航的运营方。在标准化混战期，它采用 **35 英尺箱**，并用这一尺寸参与了与 [[orgs/matson]] 的对立。

## 关键事实

| 项目 | 内容 |
|---|---|
| 控制人 | [[people/malcolm-mclean]] |
| 总工程师 | [[people/keith-tantlinger]] |
| 箱型选择 | 35 英尺 |
| 选择原因 | 宾夕法尼亚州等地公路法规限制卡车拖车最大长度 35 英尺 |
| 专利动作 | 1965 年放弃[[artifacts/corner-casting]]专利 |
| 标准立场 | 主张以自家规格为基准，与美森代表在会议室「拍桌子瞪眼」 |

## 证据与不确定性

- 来源称其为「麦克莱恩自己的海陆公司」，但**没有交代它是否就是 1955 年收购的泛大西洋轮船公司改名而来**。二者关系在本 Wiki 中记为待核实，见 [[orgs/pan-atlantic|泛大西洋轮船公司]]。
- 35 英尺的历史合理性（匹配美国公路法规）来自来源，与业界通行叙述一致，但仍属二手。
