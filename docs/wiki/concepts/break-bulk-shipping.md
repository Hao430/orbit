# 件杂货运输（Break-bulk Shipping）

集装箱之前的主流海运形态：货物以单件、散装形态（麻袋、木桶、木箱、捆包）分别装卸。本来源把它作为集装箱的**对照基线**。

## 装载形态（来源列举）

| 货物 | 包装 |
|---|---|
| 咖啡豆 | 麻袋 |
| 威士忌 | 木桶 |
| 精密机床零件 | 油纸 + 木箱 |
| 棉花 | 自捆成大包 |

不同形状、不同重量的货，都得设法装进同一个船舱。

## 一次跨国运输的完整流程（打字机案例）

来源用 1953 年一位美国商人把芝加哥打字机卖到伦敦的过程，逐环节拆解：

| 步骤 | 操作 | 动作类型 |
|---|---|---|
| 1 | 工厂 → 搬上卡车 | 装 |
| 2 | 卡车 → 芝加哥火车站 → 卸下 → 搬进火车车厢 | 卸 + 装 |
| 3 | 火车 → 纽约港 → 卸下 → 搬进码头仓库堆放等船 | 卸 + 装 |
| 4 | 仓库 → 搬出 → 放进绳索吊网 → 起重机吊进货轮船舱 | 卸 + 装 |
| 5 | 船舱内由另一批工人像玩俄罗斯方块一样码放 | 堆叠 |
| 6 | 抵伦敦 → 整套流程**倒着再来一遍** | 卸 + 装 ×N |
| 7 | 英国火车 → 英国卡车 → 百货商店 | 卸 + 装 |

来源的结论：**同一批货物要被不同的人用不同的工具整整拆装 6~8 次。**

## 船舱码放的技术难度

来源特别解释了为什么这一步是「极其讲究经验的技术活」：

- 大西洋风浪大；
- 若货舱码放不平衡或没塞紧，船一摇晃，几百吨货物就会在舱里翻江倒海；
- 轻则把脆弱的打字机砸成废铁，**重则导致整艘船重心偏移、倾覆沉没**。

## 对应的成本结构

| 项目 | 数值 |
|---|---|
| 中型货船一年中在港口装卸的时间 | 超过一半 |
| 海上航行成本占比 | 25%~40% |
| 码头装卸与港口停留占比 | **60%~75%** |
| 人工规模（一艘船靠岸） | 上百名码头工人干一整周 |

## 不确定性与争议

- 「6~8 次拆装」是数量级估算，不同航线与货种会有差异；
- 「超过一半时间在港口」引自[[people/marc-levinson|莱文森]]，未注明统计口径与样本年份；
- 来源未讨论件杂货运输在某些货种（重大件、散装液体、干散货）上至今仍不可替代。
