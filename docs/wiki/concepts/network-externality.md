# 网络外部性（Network Externality）

来源称其为集装箱的**第四个核心经济学机制**。

## 来源的通俗定义

用微信类比：

> 「如果全世界只有你一个人有微信，那微信一文不值；但用微信的人越多，这个网络的价值就呈指数级暴涨，你就越离不开它。」

## 在航运网络中的运作方式

来源给出了完整的正向循环：

```
港口吞吐量 ↑
  → 停靠班轮航线密度 ↑
  → 船公司竞争更充分 + 不用绕道中转
  → 单箱运费 ↓、运达时间 ↓
  → 吸引工厂在港口周边建厂（长三角、珠三角）
  → 货源 ↑
  → 吞吐量 ↑ （回到起点）
```

来源用的具体例证：从[[places/ports|深圳盐田港]]出发，几乎每天都有直达欧美主要港口的快船，不用绕道中转。

## 结论：产业集群的锁定效应

这是本来源中论证最锋利的一段。它解释了为什么工厂明知中国沿海工资上涨，仍然不愿迁走：

> 「哪怕你那个地方的人工工资只有中国的一半，你也会痛苦地发现：你的原材料运不进来；你的成品造出来之后，要在码头上等两个星期才有一班船，而且还要去新加坡或釜山中转；单箱运费直接翻倍，交货期完全没法保证。」

也就是：**劳动力成本优势会被物流网络的劣势完全抵消。** 来源称之为「恐怖的正向循环和马太效应」。

## 与规模经济的区别

| 维度 | [[concepts/economies-of-scale]] | 网络外部性 |
|---|---|---|
| 载体 | 单条船 | 整个网络 |
| 机制 | 单位成本随规模下降 | 网络价值随节点/连接数上升 |
| 受益者 | 船东 | 所有接入网络的工厂、港口、船公司 |
| 后果 | 运费下降 | 产业地理锁定 |

两者叠加：单船变大降低单位成本 → 航线更密 → 网络更强 → 更多工厂聚集 → 货源更足 → 支撑更大单船。这是自我强化的组合。

## 关系

**出链**
- 建立在 → [[concepts/economies-of-scale|规模经济]] 之上
- 锁定 → 产业集群（长三角、珠三角）
- 依托 → [[places/ports|盐田港]] 等高密度港口
- 强化 → [[hub/containerization|集装箱化]] 的不可逆性

**入链**
- [[concepts/standardization|标准化]] 是网络形成的前提（无标准就无网络）

## 不确定性与争议

- 「指数级暴涨」是修辞，来源未给出网络价值的量化模型（Metcalfe 定律等）；
- 来源把网络效应视为单向强化，未讨论**港口过度集中带来的韧性风险**——这一点在[[concepts/supply-chain-resilience|供应链韧性]]页里有交叉；
- 「工资一半仍搬不走」这一论断是作者的推论，缺乏实证数据支撑。
