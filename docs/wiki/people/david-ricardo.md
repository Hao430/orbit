# 大卫·李嘉图（David Ricardo）

古典经济学家，[[concepts/comparative-advantage|比较优势]]理论的提出者。本来源用该理论解释：为什么运输成本必须先降下来，国际分工才可能成立。

## 在本来源中的角色

仅作为理论来源被引用，未涉及其生平。视频的推理链条是：

1. 比较优势说各地应按相对优势分工、再通过贸易交换获益；
2. 但分工要划算，**运输费必须足够低**；
3. 传统件杂货运输下，港口装卸漫长、周转慢、破损与被盗，会把省下的劳动力成本吃掉，部分货物损耗比例可能超过 10%；
4. [[hub/containerization|集装箱化]]压低这些成本后，「从澳洲运原料到东亚、加工后运成品到欧美」的总成本才可能低于在消费国就地生产。

## 证据与不确定性

- 来源未给出《政治经济学及赋税原理》（1817）等原始文献出处。
- 「比较优势」在来源中被简化为「按相对优势分工」，省略了机会成本的核心论证。
