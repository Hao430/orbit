# 集装箱化（主题导航）

本页从原来的「大杂烩概念页」降级为**主题导航入口**。原先混在这里的机制、实体、事件已各自独立成页。

## 一句话定义

用标准化金属箱作为运输单元，使货物在公路、铁路、海运之间不经拆箱即可转运；其经济本质是**把跨系统的接口转换成本压到接近零**。

## 四大机制（各自独立成页）

| 机制 | 页面 | 一句话 |
|---|---|---|
| 交易成本下降 | [[concepts/transaction-cost]] | 拆装 6~8 次 → 1 次；破损、盗窃、等待全部削减 |
| 标准化 | [[concepts/standardization]] | 尺寸 + 接口双层标准，消除跨系统摩擦 |
| 规模经济 | [[concepts/economies-of-scale]] | 三次方载货量 vs 二次方成本；24000 箱仍只需 20~25 名船员 |
| 网络外部性 | [[concepts/network-externality]] | 航线密度 → 运费更低 → 工厂聚集 → 自我强化 |
