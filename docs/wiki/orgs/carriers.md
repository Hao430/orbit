# 集装箱航运企业（马士基 / 中远海运 / 地中海航运）

本页合并记录来源中用于说明**船舶巨型化**的三家企业。来源对它们只给了载箱量，没有其他信息。

## 规模经济的三次方-二次方论证

来源用几何学解释巨型化的经济性：

- 载货量 ∝ 船体长宽高的**三次方**；
- 造船钢板面积、水流阻力 ≈ **二次方**；
- 结论：船造大一倍，载货量可能翻两三倍，但造船成本与油耗不会翻两三倍。

**人力成本侧的对照**：2000 箱船需 20~25 名船员，2 万 4000 箱船**仍是 20~25 名**。平摊到每箱的船员工资、燃油、折旧趋近于零。
