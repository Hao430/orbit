# 麦克莱恩卡车运输公司（McLean Trucking）

[[people/malcolm-mclean|马尔科姆·麦克莱恩]]从一辆二手卡车起家建立的公路运输企业，1950 年代初做到全美第五大卡车公司。

## 关键数据

| 项目 | 数值 |
|---|---|
| 起点 | 一辆二手卡车（1930 年代） |
| 1950 年代初规模 | 全美第五大卡车公司 |
| 车队规模 | 1700 多辆卡车 |
| 个人身家 | 百万美元级 |
| 出售时间 | 1955 年 |
| 出售金额 | 约 600 万美元 |

## 叙事功能

在来源中，这家公司承担一个反衬：**守着这门生意本来已经可以过得不错**，但麦克莱恩始终惦记「货到了码头，为什么非得再倒腾一遍」。出售它是为了跨过监管壁垒进入航运。

## 关系

**出链**
- 由 → [[people/malcolm-mclean|麦克莱恩]] 创立

**入链**

- 600 万美元的售价与 700 万美元的收购价并列出现，来源未说明差额如何补足。
