浏览器把文档变成像素，需要经过解析、样式计算、布局、绘制与合成。任何一环出现长任务，都会体现为掉帧。

## 关键阶段

1. 解析 HTML 与 CSS，构建 DOM 与 CSSOM
2. 样式计算，生成渲染树
3. 布局（Reflow）计算几何位置
4. 绘制（Paint）生成绘制指令
5. 合成（Composite）交给 GPU 上屏

理解管线之后，才知道哪些属性会触发重排，哪些只会触发重绘，哪些可以完全交给 [[合成与分层]] 处理。
现代浏览器还会把部分计算下沉到 [[WebAssembly]]，例如编解码与图像处理。
优化手段的取舍参考 [[性能预算]]。
